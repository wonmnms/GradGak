# 초기 학점 데이터 검증 기록

## 출처와 확인 범위

- 자료: 소프트웨어학부 공학/일반 졸업이수요건 안내(2026ver)
- URL: https://cs.kw.ac.kr/program/requirement.php?admin_mode=read&make=&no=2975&page=1&search=&site_type=3
- 조회일 및 사용자 원본 대조 확인일: 2026-10-31
- 확인 근거: 사용자가 이 개발 채팅에서 “학점표 대조했어 일치해”라고 확인함.
- 적용 범위: 소프트웨어학부 2024학번, software/ai 두 세부전공, engineering/general 프로그램.
- 일반프로그램 전공 학점은 단일전공 기준이다.

## 확인된 학점 값

| 프로그램 | 항목 | 학점 | 적용 메모 |
| --- | --- | ---: | --- |
| 공학·일반 | 총 졸업학점 | 133 | 두 프로그램을 별도 규칙으로 저장 |
| 공학·일반 | 필수교양 | 1 | 과목 목록·면제 조건은 별도 확인 |
| 공학·일반 | 균형교양 | 30 | 영역·과목 수 조건은 별도 확인 |
| 공학 | 수리와자연·기초교양 | 12 | 수학·과학별 하위 조건 별도 확인 |
| 공학 | 공학주제 | 60 | 설계 12학점 포함 |
| 공학 | 설계 | 12 | 공학주제의 부분집합이며 별도 가산하지 않음 |
| 일반 | 전공 | 60 | 단일전공 기준 |

이 기록의 검증 완료는 위 학점 값에 한정한다. 전체 졸업요건의 검증 완료를 뜻하지 않는다.
설계와 공학주제를 합산하거나, 공학과 일반의 총학점을 합산해서는 안 된다.

## 아직 입력하거나 확정하지 않은 항목

- 일반프로그램의 기초교양 별도 기준: 미확인. 0학점 또는 면제로 추정하지 않는다.
- 교양의 영역·과목 수·면제 조건과 각 영역 인정 과목 목록.
- 학수번호, 공학 필수과목별 학점, 프로그램별 과목 인정 목록과 대체 인정의 실제 데이터.
- 학부 확인이 필요한 예외 처리. 공통 비학점 요건 및 인공지능 세부전공필수는 아래 기록 참조.

현재 데이터만으로 최종 졸업 가능 여부를 판정해서는 안 된다.

## 세부전공필수 과목 그룹의 추가 검증

2026-10-31 사용자가 이 채팅에서 “과목 그룹 조건과 5과목 학점도 대조. 일치.”라고 확인했다.

- 규칙 근거: 위 졸업요건 안내의 세부전공필수 교과목 이수 항목.
- 과목명·학점 근거: https://www.kw.ac.kr/ko/univ/ai02_4.jsp 의 교육과정 표.
- 인공지능전공: 인공지능, 빅데이터처리및응용, 컴퓨터비전, 기계학습, 딥러닝실습 중 3과목 이상.
- 위 5과목은 각각 3학점이다.
- 공학·일반프로그램 공통이며 소프트웨어전공에는 이 세부전공필수 조건이 없다.
- 공통 규칙은 현재 프로그램별 졸업요건에 각각 연결한다. 판정 시 중복 검사하지 않는다.
- 학수번호·이수구분·개설학기는 이번 대조 범위 밖이며 NULL로 저장한다.
- 과목 자체는 내부 course_id로 식별한다. 과목명·학과가 같은 후보가 여러 개면
  시드 입력을 중단한다. 이름이 같다는 이유로 자동 확정하지 않는다.
- 과목의 source_id는 교육과정 자료, 그룹의 source_id는 졸업요건 자료를 가리킨다.

```powershell
docker compose exec backend python -m app.seed_official_ai_group
```

이 시드는 과목 5개, 그룹 2개, 그룹·과목 연결 10개를 적재한다.
학수번호를 확인하면 별도 검토 후 기존 과목의 실제 학수번호를 보완한다.

## 공통 비학점 요건의 추가 검증

2026-10-31 사용자가 졸업논문·작품 제출 및 '가' 판정, TOPCIT 응시,
두 세부전공의 공학·일반프로그램 공통 적용 여부를 원본 대조하여 “일치”라고 확인했다.

- 출처: 위 소프트웨어학부 공식 졸업요건 안내의 공통 요건 항목.
- `thesis`: 요청의 `thesis_passed`가 true여야 한다.
- `topcit`: 요청의 `topcit_taken`이 true여야 한다.
- 학번·세부전공별 규칙 정의만 저장한다. 학생 개인의 통과·응시 상태는 저장하지 않는다.
- 해당 모델은 검증된 규칙을 위한 것으로 출처·확인자·확인일을 필수로 기록한다.
- 특수 인정 및 예외 처리는 이 두 불리언 규칙만으로 자동 판단하지 않는다.

```powershell
docker compose exec backend python -m app.seed_official_common
```

두 세부전공에 각각 2개씩, 총 4개의 공통 비학점 규칙을 저장한다.

## 공학 필수과목과 기초교양 하위 조건의 추가 검증

2026-10-31 사용자가 아래 원본 대조표에 “일치”라고 확인했다.
근거는 졸업요건 안내의 공학프로그램 표와 ‘2024학년도 입학자부터 적용’ 항목이다.

- 수학 최소 6학점, 기초과학 최소 3학점을 포함해 두 영역 합계 12학점 이상.
- 필수 이수: C프로그래밍, 고급C프로그래밍및설계, 스마트사회와인공지능,
  공학설계입문, 이산수학.
- 산학협력캡스톤설계1·2 중 1과목 이수.
- 이번 대조는 조건·과목명에 한정한다. 과목별 학점·학수번호·이수구분·과목명 변경의
  대체 인정은 확인하지 않았으므로 추정하지 않는다.
- 필수 이수 5개는 각각 1과목짜리 그룹으로, 캡스톤은 2과목 중 최소 1과목 그룹으로 저장한다.
- 위 규칙은 두 세부전공의 공학프로그램에만 연결한다.
- 수학·기초과학과 설계의 부모 영역을 parent_category_id로 기록해 중첩 관계를 표현한다.

```powershell
docker compose exec backend python -m app.seed_official_engineering
```

공학 그룹 12개(세부전공별 6개), 그룹·과목 연결 14개,
수학·기초과학 하위 영역 4개를 저장한다. 과목은 7개를 공유한다.
미확인 과목별 학점은 NULL로 보관하며 0학점으로 간주하지 않는다.

## 입력과 조회

저장소 루트의 PowerShell에서 DB 마이그레이션을 적용한 후 실행한다.

```powershell
docker compose exec backend python -m app.seed_official_credits
```

4개 졸업요건 범위, 16개 영역별 학점 규칙, 출처 1개와 연결 기록 4개를 적재한다.
2099년 TEST 가상 데이터와 구분한다. 재실행은 기존 레코드를 재사용한다.
같은 키의 기존 값이 다르면 오류로 중단하며, 하나의 트랜잭션을 롤백한다.
