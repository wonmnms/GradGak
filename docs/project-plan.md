# Project Plan

## 1. 프로젝트 개요

### 프로젝트명

광운대학교 졸업요건 분석 및 수강계획 시뮬레이터

### 한 줄 소개

광운대학교 학생의 이수과목을 바탕으로 현재 졸업요건 충족 여부를 분석하고, 앞으로 필요한 수강계획을 확인할 수 있도록 하는 웹 서비스이다.

## 2. 프로젝트 배경

대학의 졸업요건은 입학년도, 학과, 전공 및 복수전공 여부 등에 따라 달라질 수 있다.

학생이 졸업을 준비하기 위해서는 학교의 교육과정과 학사 관련 안내를 여러 곳에서 확인하고 자신의 이수내역과 직접 비교해야 한다.

본 프로젝트에서는 이러한 과정을 자동화하여 학생이 자신의 졸업 진행 상황과 앞으로 필요한 과목을 쉽게 확인할 수 있도록 한다.

## 3. 프로젝트 목표

1. 학생의 이수내역을 바탕으로 졸업요건을 자동으로 분석한다.
2. 현재 충족한 졸업요건과 부족한 요건을 명확하게 제공한다.
3. 향후 수강과목을 추가하여 졸업 가능 여부를 시뮬레이션할 수 있도록 한다.
4. 향후 졸업에 필요한 과목을 추천할 수 있도록 확장한다.
5. 입학년도별 학사 규정을 구분하여 정확하게 적용할 수 있는 구조를 설계한다.

## 4. 대상 사용자

- 광운대학교 학부 재학생
- 자신의 졸업요건 충족 여부를 확인하려는 학생
- 향후 수강계획을 세우려는 학생

## 5. 개발 범위

### Phase 1 — 졸업요건 분석

최초 구현 범위이다.

- 입학년도 및 학과 선택
- 이수과목 입력
- 졸업학점 계산
- 졸업요건 분석
- 부족한 요건 표시
- 필수 미이수 과목 표시

### Phase 2 — 수강계획 시뮬레이션

- 앞으로 수강할 과목 추가
- 수강 후 졸업요건 충족 여부 재계산
- 학기별 수강계획 관리
- 선수과목 및 개설학기 반영

### Phase 3 — 수강계획 추천 및 최적화

- 졸업에 필요한 과목 추천
- 수강 가능 학점을 고려한 계획 생성
- 졸업 예정 학기 예측
- 다양한 조건에 따른 수강계획 비교
- 최적 수강계획 탐색

### Phase 4 — 확장

- 복수전공 및 부전공 지원
- 다양한 학과 지원
- 다양한 입학년도 지원
- 자연어 기반 결과 설명

## 6. 데이터 범위

초기 개발에서는 광운대학교 소프트웨어학부를 대상으로 필요한 학사 및 교육과정 데이터를 확보한다.

이후 프로젝트 진행 상황에 따라 지원 학과 및 입학년도를 확대한다.

## 7. 개발 방향

졸업요건 판정 로직은 임의의 추론이나 AI에 의존하지 않고, 공식 학사자료를 기반으로 한 명시적인 규칙을 통해 처리한다.

학사 규정 및 교육과정 원본 데이터를 구조화된 규칙 데이터로 변환하는 과정에는 AI를 보조 도구로 활용할 수 있다. 단, AI가 추출·정리한 데이터는 반드시 원본 자료와 대조하여 사람이 검증한 뒤에만 실제 판정 로직에 반영한다.

학사 규정 및 교육과정 데이터와 실제 판정 로직을 분리하여 향후 규정 변경에 대응할 수 있도록 설계한다.

## 9. 성공 기준

최소한의 사용자 입력만으로 현재 졸업요건 충족 여부를 확인할 수 있어야 한다.

또한 졸업요건을 충족하지 못한 경우 어떤 요건이 부족한지 사용자가 명확하게 확인할 수 있어야 한다.
