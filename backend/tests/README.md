# 이수내역 PDF 파서 테스트

## 검증 자료와 개인정보

공개 테스트는 가상의 과목·연도·성적으로 만든 PDF 바이트와 추출 표를 사용한다.
실제 PDF를 코드에 포함하거나 실제 이수내역을 테스트 데이터로 복사하지 않는다.
실제 변환본과 직접인쇄본, 원본과 대조한 과목별 기대 JSON은 Git 밖의 로컬 위치에서만 사용한다.
검증은 제공된 저장 형식에 한하며, 다른 PDF 생성 방식까지 일반화하지 않는다.

## 지원하는 표 구조

- 학기 구획: `YYYY학년도 1학기/2학기`, `YYYY학년도 계절학기(하계/동계)`.
- 과목 헤더: `과목명`, `이수구분`, `학점`, `성적`, `재수강여부`. 의미가 명확한 헤더 별칭도 인식한다.
- 같은 학기가 여러 페이지에 반복되면 행을 순서대로 이어 붙인다. 이전 표와 같은 열 구조가 확인되는 연속 표도 처리한다.
- 각 행에 명시적으로 연도·학기가 있는 일반 표도 지원한다. 일반 표의 빈 연도·학기를 임의로 이전 행에서 가져오지 않는다.
- 학수번호 열이 없으면 `course_code=null`이다. 학번 라벨이 없으면 입학년도를 수강 연도로 추정하지 않고 `null`을 반환한다.
- 빈 성적은 `grade=null`이다. 성적에 붙은 `(삭제)`를 제거하거나 그 행을 버리지 않는다.
- `is_retake`는 재수강 열의 명시적 표시만 반영한다. 삭제 성적이라고 재수강으로 추론하지 않는다.
- F·NP, 재수강과 이전 이력도 보존하며 과목 매칭·중복 제거·졸업요건 판정을 하지 않는다.
- 중첩된 외곽 레이아웃 표는 제외해 안쪽 표와 중복 집계하지 않는다. 경고의 `row`는 남은 표의 페이지·표 순서에서 모든 행을 세는 1부터 시작하는 누적 번호다. 헤더·빈 행도 포함한다.
- 과목 헤더를 인식했지만 추출 과목이 0개면 HTTP 200과 빈 목록을 반환한다. 모든 행 실패 시 행별 경고를 유지하고, 헤더·빈 행뿐인 경우에는 첫 헤더 행의 빈 표 경고를 추가한다. 표 자체가 없을 때만 `TABLE_NOT_FOUND`다.
- 모호하거나 인식하지 못한 과목 행은 경고로 알린다. 경고·오류에는 원문 행·파일명·개인정보를 넣지 않는다.
- 이미지뿐인 페이지는 OCR 없이 `NO_TEXT_LAYER`다. 텍스트 페이지와 섞여도 조용히 누락시키지 않는다.

## 공개 회귀 테스트

저장소 [README](../../README.md#백엔드-로컬-테스트-python-312)의 Python 3.12 환경에서 실행한다.

```powershell
python -m pytest
python -m ruff check .
python -m ruff format --check .
```

합성 PDF로 학기 구획·계절학기·페이지 연속·반복 헤더·빈 성적·삭제 성적·재수강 독립성·누락 없는 다중 페이지 변환과 HTTP 업로드 경로를 검증한다.

## 실제 샘플을 사용하는 로컬 검증

`test_private_klas_samples.py`는 아래 환경변수를 설정한 경우에만 실행한다. 설정하지 않으면 건너뛴다.
경로는 코드에 하드코딩하지 않고, 파일은 Git 밖 또는 Git에서 제외한 `backend/tests/private_samples/`에 둔다.

```powershell
$env:KLAS_TEXT_PDF = '로컬 텍스트 PDF의 절대 경로'
$env:KLAS_IMAGE_PDF = '로컬 이미지 PDF의 절대 경로'
$env:KLAS_EXPECTED_JSON = '로컬 기대 JSON의 절대 경로'
python -m pytest -q tests/test_private_klas_samples.py
```

기대 JSON은 `Course` 객체 배열이다. 파서 결과에서 자동 생성하지 않고 원본 PDF를 별도로 직접 대조해 작성한다.
테스트는 과목 수뿐 아니라 순서와 각 필드를 비교하며, 실패 메시지에 개인정보·원문 과목별 결과를 출력하지 않는다.
직접인쇄본은 API의 400 / `NO_TEXT_LAYER`도 확인한다. 이 테스트를 실행해도 원본이나 추출 JSON을 서버 파일·DB에 저장하지 않는다.

새 샘플은 표 구획과 열, 성적·재수강 표기와 페이지 나눔을 대조한 뒤 지원 범위를 보완한다.
색상만으로 가려진 개인정보는 숨은 텍스트에 남을 수 있으므로 비식별본의 텍스트와 메타데이터까지 확인한다.
`private_samples/` 외의 경로에 파일을 두면 ignore 규칙이 적용되지 않을 수 있다. 커밋 전에 `git status`와 `git diff --cached`를 확인한다.
